# 扩展模型以预测5个图像优化参数

## 目标
将当前只预测2个参数（曝光、饱和度）的模型扩展为预测5个重要图像优化参数：
1. **曝光** - 调整图像亮度
2. **对比度** - 调整图像对比度
3. **饱和度** - 调整色彩鲜艳度
4. **高光** - 调整高光区域
5. **阴影** - 调整阴影区域

## 实施步骤

### 1. 修改训练配置
- 更新 `training/config.py` 中的 `output_dim` 从 2 改为 5
- 更新参数范围配置，包含所有5个参数

### 2. 修改模型架构
- 确认 `models/model.py` 支持5个参数输出
- 验证 `models/regression_head.py` 的回归头部可以处理5维输出

### 3. 更新颜色调整函数
- 修改 `start.py` 中的 `apply_color_adjustments` 函数
- 添加对比度调整逻辑
- 添加高光调整逻辑
- 添加阴影调整逻辑
- 更新参数提取和打印逻辑

### 4. 更新推理脚本
- 修改参数提取代码，从2个参数扩展到5个参数
- 更新参数应用顺序

### 5. 更新README文档
- 更新参数说明部分，添加对比度、高光、阴影的详细说明
- 更新参数范围表格

## 预期效果
- 模型能够预测5个关键图像优化参数
- start.py能够应用所有5个参数的调整
- 更全面的图像优化效果
